# Build verification

v1.0.44 was built for ESP32-S3 with ESP-IDF v5.5.3 using the bundled components and neutral artwork. The application fits the original OTA partition. Normal compilation does not require private services or commercial fonts.

The source follows the v1.0.44 r2 functional baseline. Neutral asset generation keeps that version's image interfaces and font character sets. Third-party notices are retained.

Compilation is separate from hardware acceptance. This neutral build has not been installed or accepted on a physical screen; touch, phone updating, Bluetooth coexistence and vehicle behavior require their own tests.
